### 基本ルール

#### 対戦の流れ

- プレイヤーはシロアリ側・防除業者側を選び、CPUと対戦する
- 先攻・後攻はじゃんけん、またはコイントスで決め、以降は交互に行動する
- 山札は陣営ごとに分ける（シロアリ山札50枚・防除山札50枚）。中立カードは両方の山札に入る
- 山札が尽きても捨て札を混ぜ直さない
- 初期手札は5枚。ターン開始時のドローはない（補充はターンの終わりに行う）

#### コスト（行動力）

- 毎ターン開始時に行動力が3になる。余った行動力は持ち越さない
- カードを使うときに、カードごとのコストを行動力から払う（コストはカード一覧を参照）
- 女王アリは手札から出すカードではないため、コストはない

#### カードの使い方

- 行動力が足りる限り、1ターンに使えるカードの枚数に上限はない
- ただし**シロアリカードは、1ターンに同じポイントへ1枚まで**
- 防除・駆除・イベント・中立カードはこの制限を受けない。薬剤散布の連続使用や、薬剤散布・バリア工法とベイト工法の併用ができる
- 偵察・妨害は、相手の手札がないときは使えない
- 予知は、自分の山札の上3枚から1枚を手札に加え、残りを好きな順で山札の下に置く
- イベントカード・中立カードも手札に入り、持ち主が任意のタイミングで使う

#### 補充

- ターンの終わりに、手札が5枚になるまで自分の山札から引く。5枚を超えている場合は引かない
- 手詰まり防止：1枚も使わなかったターンは、補充の前に手札を1枚捨てて1枚引ける（任意）
- 入れ替えルール（手札1枚を山札の下に戻して引く）は廃止

#### 手札上限

- 手札上限は7枚
- 自分のターン終了時に8枚以上あれば、7枚になるまで好きなカードを捨てる
- 捨てたカードは捨て札になり、山札には戻らない

#### 侵食と勝利条件

- 1つのポイントにシロアリカードが**3枚**重なると完全侵食となり、そのポイントは潰れる
- **シロアリ側の勝利**：8ポイント中、過半数（5ポイント）を完全侵食する
- **防除業者側の勝利**：シロアリ山札がなくなるまで守りきる

### ポイント

#### 置ける場所の対応表

家は普段、換気・防湿が効いていて乾いている設定。ヤマトシロアリは水を運べないため、水回りにしか置けない。

| ポイント | 状態 | 置ける種類 |
| --- | --- | --- |
| 浴室・洗面所 | 水回り | ヤマト・イエ |
| キッチン | 水回り | ヤマト・イエ |
| 床下・土台 | 乾燥箇所 | イエ |
| 玄関・框 | 乾燥箇所 | イエ |
| 庭の枯れ木 | 乾燥箇所（特殊） | イエ |
| ウッドデッキ | 乾燥箇所 | イエ |
| 梁・柱 | 上部 | イエ・カンザイ |
| 屋根裏・天井 | 上部 | イエ・カンザイ |

- 対応表はクライアントの確認を取る前提

#### 特殊ポイント：庭の枯れ木

- 完全侵食（倒れる）には4枚必要
- 倒れると、全ポイントの完全侵食に必要な枚数が3枚から2枚に減る

### シロアリカードの構造

シロアリカードは「種類」と「カースト」の組み合わせで構成する。

- **種類**（ヤマト・イエ・カンザイ）：置けるポイントを決める
- **カースト**（職アリ・兵アリ・羽アリ・女王アリ）：効果を決める
- 例：「ヤマトシロアリの職アリ」「イエシロアリの兵アリ」

#### 羽アリと女王アリ

- 女王アリは山札に入れず、種類ごとに1枚ずつ別に用意する
- 羽アリを置くと、次の自分のターン開始時に女王アリと入れ替わる。羽アリは捨て札へ
- 女王アリになったとき、同種の職アリを山札から2枚手札に加える
- 女王アリになる前に羽アリを駆除されると、女王アリにはならない

#### 兵アリ

- 兵アリがいるポイントへの薬剤散布を1回無効化する（兵アリ1枚につき1回）
- ベイト工法には耐えられない

### カード効果の共通ルール

- 「次の自分のターンまで」の効果は、使った人の次のターン開始時に切れる
- 完全侵食されたポイントは、すべてのカードの対象外
- 山札から特定のカードを手札に加える効果は、対象が山札に残っていなければ空振りになる
- ベイト工法は、置いてから2回目の自分のターン開始時に発動し、そのポイントのヤマト・イエシロアリをすべて除去する（カンザイシロアリは対象外）。同じポイントへの重ね置きは不可（仮）
- バリア工法は、置いてから3ターンの間シロアリカードを置けなくする
- 大量発生は、シロアリ側の次のターン開始時まで、そのポイントに防除・駆除カードを置けなくする
